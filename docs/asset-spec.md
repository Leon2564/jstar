# 素材规格

界面上每个占位框都标了它需要什么。汇总如下（第一期）。

| 用途 | 规格 | 数量 | 备注 |
|---|---|---|---|
| 首页竖屏短视频 | 1080×1920，6–8 秒循环，无声 | 每人 1 条，共 5 条 | 全屏播放，看镜头 |
| 首页横屏版（桌面） | 1920×1080，同素材另剪 | 5 条 | |
| JSTARS 全身像 | 竖 1080×1920，横 1920×1080 | 每人各 1 张 | 优先实拍 |
| 手写签名 | 透明 PNG，宽 ≥800 | 5 个 | |
| 陪伴首页场景 | 1080×1920，早/午/晚 | 每人 3 张，共 15 张 | |
| 首期卡面 | 630×880（@2x 1260×1760） | 每人 6 张，共 30 张 | SSR 用实拍，其余 AI 生成并标注 |
| 卡面语音 | 单声道 48kHz，8–15 秒 | 每张卡 1 条 | |
| 加载页语音 | 1–2 秒 | 每人 1–2 条 | |
| 活动横幅 | 1029×390 | 3 张 | |
| 玩法演示视频 | 屏幕录制 | 4 条 | 用原型直接录，不需另外拍 |

规则（写进「风格圣经」）：

1. 构图一律看镜头，第一人称视角。
2. 色调统一：藏青底 + 玫瑰粉光；保留皮肤纹理，不磨皮。
3. AI 生成一律以实拍为参考图，只做场景/时段延伸；视频只做呼吸、眨眼、发丝等小动作。
4. 实拍与 AI 生成分开标注，实拍进最高稀有度。

接入方式：素材上传 CDN 后，在管理端填卡牌的 `artUrl` / `voiceUrl`；界面会自动从占位切换成真实素材，前端不需要改代码。
