# 多语言

支持四种语言：日文（ja，基准）、繁体中文（zh-Hant）、英文（en）、韩文（ko）。

- 词条：`apps/web/src/i18n/*.ts`。`ja.ts` 是基准，其余三种语言的键必须完全一致——由 TypeScript 和 `tests/unit/i18n.test.ts` 双重保证（键集合、占位符集合、非空、en/ko 不得混入日文假名）。
- 首次访问按浏览器语言选择；用户可在年龄确认页、菜单、桌面导航栏切换，选择会持久化，并同步到 `<html lang>`。
- 只有当前语言的词条会被下载（其余三种是动态 import 的独立 chunk），字体也按语言加载：日文/英文用 Shippori Mincho + Zen Kaku Gothic，繁中用 Noto Serif/Sans TC，韩文用 Noto Serif/Sans KR。
- 姓名显示：日文与繁中显示原名（唯井まひろ / 唯井真尋），韩文用韩字、姓在前，与人设一致（타다이 마히로 / 야기 나나 / 운파이 / 나나세 앨리스 / 후카다 에이미；名：마히로 / 나나 / 운파이 / 앨리스 / 에이미），英文显示罗马字（Mahiro Tadai）；竖排书写只对日文与繁中启用。
- 法律文书（`apps/web/src/pages/legalText.ts`）只有日文、繁中、英文三版；韩文界面显示英文原文，顶部有韩文说明。
- 人设台词也分语言：`apps/agent/app/personas/*.yaml` 里每条婉拒、身份说明、开场白都有四语版本。
- v1.1 的场景与台词（`packages/shared/src/scenes`、`lines`，以及日历 / 她的消息 / 约定 / 礼物的模板）每条文字都有 ja / zh-Hant / en / ko 四语，2026-09-28 由 SOTA 模型审校并写韩语（`docs/review/v11-lines-review.md`）；读取一律经 `localText`，缺韩语时退回英文，其余退回日文。

**界面词条仍是草稿**，上线前需要母语者审校，尤其是每位艺人的语气差异。
