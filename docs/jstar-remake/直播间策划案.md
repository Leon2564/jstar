# JSTAR 新版媒体复刻策划案

## 核心体验

保留本地项目已经成立的播放与互动结构，以新版 Lark 场景底图统一美术空间。人物通过预渲染的 Hero、待机、说话、入场、反应和剧情片段保持连续存在感；动态回复由已授权 AI 音色承担。

## 首批角色与空间

首批以深田えいみ为制作基线。主空间延续本地角色设定：东京夜景中的高层私密套房，落地窗、丝绒扶手椅、玫瑰金细节、大理石与深色木材形成克制的高级感；室内使用低饱和蓝色夜光和少量玫瑰暖光。空间不是陈列式豪宅，要有她刚刚生活过的痕迹，但固定建筑、家具和灯具位置必须能够跨视频保持一致。

## 生产边界

- 不依赖实时数字人层。
- 不改变现有媒体 ID 和前端路由。
- 不把单张漂亮场景直接当作成套视频资产。
- 每个主空间先建立无人标准底图，再建立人物标准帧，最后生成循环与动作。
- 9:16 与 16:9 共享同一空间设定、服装、发型和光线逻辑。
- AI 语音仅使用已取得授权并完成相似度、日语发音和延迟验收的音色。

## 当前内容配置

使用项目自定义配置，按本地现有媒体 ID 逐条复刻，不扩展为通用礼物舞蹈直播库。普通循环都回到对应 Hero 标准帧；剧情链使用实际上一段尾帧作为下一段起点。
