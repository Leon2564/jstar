## 二、功能

- 年龄确认拦截并在确认后回到原页面；拒绝则不可进入。
- 流程一：选人 → 免注册试聊 3 条 → 引导注册 → 注册后对话被继承。验证码错误有明确报错。
- 流程二：扫码带码 → 跨过年龄确认仍保留 → 兑换 → 翻卡 → 她说话；重复使用同一码返回「已使用」；格式错误不发请求。
- 抽卡：未登录跳注册并回到抽卡；点数不足给出提示；十连保证 SR 以上至少一张；结果可逐张揭晓；卡册与卡片详情联通。
- 后端侧：序列码一码一用（409）、积分不足（402）、免费次数不足（409）、管理接口对普通用户 403、概率和不为 1 时 400、访客试聊超额 402。

## 三、多语言

- 四种语言词条键集合与占位符完全一致（自动校验），英文与韩文不含日文假名。
- 浏览器语言自动识别（zh-TW/zh-HK/zh-CN → 繁中，ko-KR → 韩文，其余回退日文）。
- 切换语言后 `<html lang>` 同步、刷新后保持、页面无未翻译的键名残留、AI 回复按所选语言返回。

## 四、响应式

6 种视口（320、390、844 横屏、820、1280、1920）× 2 种语言 × 18 个页面，全部无横向滚动。
修复的问题：品牌标识与菜单页脚链接点击区域小于 32px。
桌面端显示完整站点导航，手机端收进菜单；会员区标签栏手机在底、桌面在顶（均有断言）。

## 五、安全

| 项 | 结果 |
|---|---|
| 聊天注入四种 XSS 载荷 | 按纯文本渲染，无弹窗、无注入节点 |
| 开放重定向四种写法 | 全部拦截，回落到安全路径 |
| 恶意 `?code=` 参数 | 不自动填入；经由年龄确认跳转时同样被丢弃 |
| 篡改 localStorage（负积分、伪造卡 ID、伪造角色） | 全部被夹紧或丢弃，应用不崩溃 |
| 损坏的 localStorage | 回落为全新会话 |
| 构建产物 | 含 CSP，无 `dangerouslySetInnerHTML`、无 `eval`、无密钥 |
| 后端鉴权 | 未登录访问受保护接口一律 401，管理接口非管理员 403 |

| 首次内容绘制 | 1.12 s | < 3 s | 达标 |

## 八·二、沉浸式首页与生成素材（新增 `immersive.spec.ts`）

从访客角度验证：
- 首屏先出海报图，随后静音内联循环播放；任何时刻最多一个视频在解码。
- 方向键、滚轮、手机滑动整屏切换；一串滚轮事件只切一位；点按钮不会误触切换；切换后读屏会播报名字。
- 访客把鼠标放在文字区阅读时暂停自动轮播，移开后继续。
- 减少动态效果：只有静图，没有视频、没有视差、不自动轮播。标签页隐藏时暂停视频。
- 视频 404：海报保留，页面照常可用。
- 手机首访流量：只下载一个小尺寸视频，媒体总量 < 3 MB。
- 320 到 1920 六种尺寸：主按钮在首屏内，无横向滚动，人物框不压文字、不压右下角新闻区。
- JSTARS 的服装与道具可以拖动和用方向键旋转，旋转时不会误切艺人；资料未到位的字段显示「事務所確認中」。
- 陪伴首页按时钟切换早／午／夜场景；加载页星空背景仍可跳过；抽卡结果的星芒只播一次。

用户体验验收中发现并修复：
- 夜景上的深色文字看不清（JSTARS、陪伴首页顶部）→ 场景页改为夜间配色，桌面资料栏加半透明面板。
- 桌面 1366 宽时人物框压到新闻区；手机上人物占位框叠在竖排名字上 → 分断点重新布局。
- 手机优先下载 AV1 大文件（很多手机只能软解，耗电）→ 只在需要全尺寸时才给 AV1。
- 过渡动画对全屏视频做模糊滤镜，节流手机上掉帧 → 去掉模糊，只保留缩放和淡入。
- 首屏最大内容绘制退步到 4.57 秒 → 海报图出半尺寸版本，并在 HTML 里按横竖屏预加载，降到 3.40 秒。
- 首包 JS 逼近 90 KB 预算 → 次要官网页面与粒子画布拆成独立按需加载的块，首包回到 87.5 KB。
